EduAI Design Tokens

Visual reference for the centralized theme system. All values live in lib/core/theme/

How to restyle the app: The entire visual identity is controlled by 3 files. Change a value there and it updates everywhere in the app.

app_colors.dart — All colors, gradients, opacity variants

app_text_styles.dart — All text styles (font family, size, weight)

app_decorations.dart — Border radii, shadows, card decorations

Barrel export: import 'core/theme/app_theme.dart'; imports everything.

static const Color primary = Color(0xFF4A90D9);
