## 1. What is EDU AI assistant

1.1 The EDU AI assistant application is intended for pupils and students of primary and secondary schools, teachers and educational institutions. It provides in particular:

- learning lessons,
- quizzes and practice activities,
- evaluation of answers and study progress,
- spaced repetition,
- study-related information,
- optional AI-based assistance,
- optional chat link with a teacher or mentor,
- other related educational and motivational features.

1.2 The Application may be used in three modes:

**a) Anonymous access** — without an account, no personal data is processed.

**b) School mode** — the educational institution is the data controller (Art. 28 GDPR); the Provider is the processor.

**c) Full access** — for users 15+; full functionality including AI; the Provider is the data controller (Art. 24 GDPR).

## 4. Technology and open source

4.1 The Application is built on Flutter (Dart) for mobile (iOS, Android) and web; backend APIs on PHP / Laravel; administration on Next.js. Synchronisation over REST API with Bearer-token authentication. Local data stored encrypted.
